
# 🏡 Vacation Rental Platform

A full-stack web application built with **Node.js, Express.js, and MongoDB** using **MVC architecture**.  
This platform allows users to rent properties for short- and long-term homestays, similar to Airbnb.

---

## ✨ Features
- **User Authentication**: Secure signup/login with session management.
- **Property Listings**: Add, edit, delete, and view rental properties.
- **Search & Filtering**: Find properties by location, price, and amenities.
- **Reviews & Ratings**: Users can leave feedback on properties.
- **RESTful APIs**: Well-structured endpoints for listings, bookings, and user management.

---

## 🛠️ Tech Stack
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **Architecture**: MVC (Model–View–Controller)
- **Authentication**: Passport.js
- **Templating**: EJS 
- **Deployment**: Render
